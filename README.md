# **Hangman Project**
### This project is a jupyter notebook containing a hangman game that can be played on normal and hard difficulties

## **Installation**
### Clone the repository
git clone https://github.com/Deividas-Juska/Hangman-Project.git
### Make sure Jupyter Notebook is installed on your machine

### Navigate to and open the Hangman Project.ipynb in Jupyter Notebook

### Select the cell containing the game code and press Ctrl + Enter to run it

## **Game Instructions**
### **Enter Your Name**
#### Upon running the code you will be prompted to enter your name, this name will be used to update your statistics on the leaderboard

### **Main Menu**
#### After entering your name, you will be taken to the main menu. In the main menu you can enter the following commands:
- `play` — Start a game of Hangman
- `hard` — Change the difficulty to Hard
- `normal` — Change the difficulty to Normal
- `leaderboard` — View the leaderboard
- `quit` - Exit the game

### **Leaderboard**
#### Upon inputting `leaderboard` leaderboard statistics by game difficulty will be outputted
#### You can then enter any input at the prompt to return to the main menu where you may enter another command

### **Playing Hangman**
#### Upon inputting `play` you will start a game of hangman based on your selected difficulty
#### In each round of Hangman, you will be prompted to enter a letter to guess a letter in the hidden word
#### The game will display the following information each round:
- The letters you have correctly guessed in the hidden word
- The number of guesses remaining
- The letters you have already guessed
#### Use this information to correctly guess the hidden word before you run out of guesses

### **Game Completion**
#### After completing the game your results will be displayed 
#### You can then enter any input at the completion prompt to return to the main menu and continue playing or enter another command
